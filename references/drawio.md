# draw.io 实现注意事项

仅在创建或修改 `.drawio` 文件时读取。这些是格式相关的实现细节，不是科研图的设计模板。

## 读取与定位

结合源文件和实际渲染确定目标页、对象、父子关系、连线及图层顺序。文件可能保存直接的 `mxGraphModel`，也可能使用压缩的 `diagram` 内容；先识别编码方式再编辑。

按对象 ID 做有范围的修改。新增 ID 保持唯一，删除对象后检查 `source`、`target`、`parent` 等引用，避免悬空连接。

## 样式与文本

- `mxCell.style` 同时包含 `key=value` 和 `text`、`ellipse` 等裸样式名。更新属性时保留裸样式名与无关属性，否则可能改变对象类型或边框。
- 同一属性可能重复出现。更新时移除该属性的旧项，再设置有效值。
- 使用 XML 库处理属性转义。HTML 标签中的字号、字体和上下标可能覆盖单元格样式，需要一起检查。
- 字符和字体能否正确显示，以目标应用的实际渲染为准。

局部样式更新示例：

```python
def patch_style(style, changes):
    tokens = [part for part in style.split(';') if part]
    keep = [part for part in tokens
            if '=' not in part or part.split('=', 1)[0] not in changes]
    keep += [f'{key}={value}' for key, value in changes.items()]
    return ';'.join(keep) + ';'
```

## 几何与连接

识别 `mxGeometry` 的绝对坐标、相对父对象坐标和连线坐标，不对所有对象盲目施加统一偏移。检查对象及文字的实际轮廓，而不仅是包围盒。

绑定 `source` / `target` 的连线通常随节点更新，自由箭头、手工折点和独立标签可能需要同步移动。确认图层顺序不会让背景或强调对象遮挡内容。

## 导出

使用环境中已有的兼容导出能力，先确认可执行文件和支持的选项，不假设固定安装路径。选择符合实际用途的预览分辨率与成图格式。

导出后查看图像；若用于投稿，再按最终插入尺寸检查文字、数学符号、裁切和背景。源文件可解析不能替代视觉检查。若环境不支持渲染，保留可编辑成果并说明尚未完成的检查。
