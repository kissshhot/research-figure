# research-figure · 科研绘图

一个用于创建和改进科研图的 Codex skill，覆盖论文、学术报告中的概念示意、方法流程、结构关系、实验设计和数据可视化。

从科学问题出发选择图形表达，保留必要的条件与依赖关系，并交付可继续编辑的源文件和经过检查的成图。针对 draw.io，提供字体、配色、公式排版和最终尺寸可读性的具体规则。

## 适用场景

- 根据论文 PDF、LaTeX 方法部分或文字描述绘制方法图。
- 解释算法流程、模块依赖、实验设计和概念关系。
- 改进已有科研图的信息层次、连线、布局和文字可读性。
- 根据真实实验数据制作对比图，并保留数据处理与绘图代码。

图形结构由内容决定，不预设固定的流水线、栏数或模板。示意图与测量数据应明确区分，不虚构数值，也不为排版整齐改变科学含义。

## 安装

将仓库克隆到本地 Codex 的 skills 目录：

```bash
git clone https://github.com/kissshhot/research-figure.git ~/.codex/skills/research-figure
```

如果设置了自定义 `CODEX_HOME`，请将目标路径改为该目录下的 `skills/research-figure`。

如果目标目录已经存在，先检查并保留其中的本地修改；不要直接覆盖。对于通过 Git 克隆的安装，可以在确认工作区干净后更新：

```bash
git -C ~/.codex/skills/research-figure pull --ff-only
```

## 使用示例

在 Codex 中明确指定 `$research-figure`，并提供材料、输出格式与使用场景。

**从论文绘制方法图：**

```text
使用 $research-figure，根据这份论文的方法部分绘制 method.drawio。
不参考已有图像，保留可编辑元素，并导出 PNG 预览。
图片用于论文跨栏排版，最终宽度约 180 mm。
```

**改进已有图：**

```text
使用 $research-figure，调整这份 draw.io 方法图。
保留算法关系，放大公式、轴标和辅助说明，必要时重排布局。
检查连线是否穿过文字，并按最终插入宽度检查可读性。
```

**绘制实验结果：**

```text
使用 $research-figure，根据提供的实验数据绘制对比图。
保留单位、统计口径和已有误差信息，交付绘图代码与成图。
```

提供最终图宽、单栏或跨栏用途、语言、目标格式，以及必须保留的符号，有助于确定合适的布局和字号。用户明确要求和出版物规范优先于默认风格。

## 默认视觉风格

采用白色画布、浅色分区背景与深色文字。颜色用于区分内容，不绑定特定算法或模块。

| 色系 | 主要文字／图形 | 浅色背景 | 边框／辅助色 |
| --- | --- | --- | --- |
| 蓝 | `#234E78` | `#EEF4FC` | `#9BB4D0` |
| 绿 | `#286432` | `#F0F8EF` | `#9DBD94` |
| 紫 | `#5146A6` | `#F1F0FC` | `#AAA0D3` |
| 红 | `#AE5050` | `#FBEAEA` | `#CE9696` |
| 金 | `#AF7B16` | `#FFF8E5` | `#D6B05E` |

- 英文标题、说明和标签：默认 **Comic Sans MS**，标题加粗、正文常规。
- 公式、数学字母及上下标：默认 **Times New Roman**，按数学语义排版。
- 中文：使用可用的苹方、思源黑体等配套字体，并检查混排效果。
- 字体不可用时应说明替代字体；仓库不包含字体文件。

## 字号与最终尺寸

以下是约 **1900–2000 画布单位宽**的 draw.io 示意图的源字号参考：

| 内容 | 源字号 |
| --- | --- |
| 总标题 | 44–48 |
| 分区标题 | 40–44 |
| 模块标题 | 38–40 |
| 正文和标签 | 36–40 |
| 公式主体 | 38–42 |
| 辅助文字 | 36 |

这些数值不是最终印刷 pt。最终正文、公式主体和关键标签以 **10–11 pt** 为目标，普通辅助文字至少 **9 pt**。其他画布宽度需要重新估算，数学上下标也需实际检查。

例如，2000 单位宽的图缩放到 180 mm 时，源字号 40 约为 10.2 pt，而源字号 28 仅约为 7.1 pt。因此，提高 PNG 分辨率不能解决最终文字过小的问题。

空间不足时优先缩短说明、换行或重排布局；同时检查文本内部 HTML/CSS 是否覆盖了默认字号。

## 输出与检查

根据任务选择可编辑源文件、生成代码和预览格式；并非每次都生成所有格式。draw.io 任务通常交付 `.drawio` 源文件及 PNG、SVG 或 PDF 成图，具体导出能力取决于运行环境。

完成前检查：

- 科学关系、符号、条件和图注是否一致。
- 信息分组与阅读顺序是否清楚。
- 是否存在重叠、裁切、异常换行或连线穿过文字。
- 公式、图例、轴标及底部说明在最终尺寸下是否可读。
- 预览是否与可编辑源文件对应。

文件能解析或导出成功，不等于视觉检查通过。环境无法完成渲染或最终尺寸检查时，应说明尚未验证的部分。
